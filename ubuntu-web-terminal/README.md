# Ubuntu Web Terminal

A lightweight Debian-compatible web terminal for Unikraft Cloud, deployed to the Frankfurt (`fra`) metro.

## Access

Open the deployed service URL in a browser and sign in with:

- Username: `root`
- Password: `unikraft`

The persistent 1 GB volume is mounted at `/data`.

## Image

`unikraft.io/iudd/ubuntu-web-terminal:latest`
